# 佐々金物様 AI活用トレーニング：講師側の準備内容

> 対象資料：「佐々金物様 AI活用トレーニングコース（案）」（全24枚）
> コース概要：全6回・隔週・各2時間（約3か月）。1回の内訳は講義20分・実演20分・実習60分・振り返り20分
> ゴール：品質と納期で元請に選ばれ、売上アップにつなげる（主な指標は売上、あわせて品質・納期を見る）

---

## 1. 全体スケジュール（講師側）

| 時期 | やること | 成果物 |
|---|---|---|
| 開講4週前 | ヒアリング（60分）、事前アンケートの送付、データ提供の依頼 | ヒアリングメモ、アンケート回答 |
| 開講3週前 | 受講前3か月の実績を受領し、基準値と目標値を確定。Copilotの手配と管理設定をIT担当・販売店に依頼 | KPI基準値シート、設定依頼書 |
| 開講2週前 | 教材データの受領と匿名化、ツールのアカウント準備、AI利用ルール案の作成 | 匿名化済み教材フォルダ、ルール案 |
| 開講1週前 | 第1・2回の教材とデモの最終確認、通しリハーサル | 第1・2回の講義資料・実習シート |

## 2. 開講前の準備

### 2.1 ヒアリング（60分）

確認項目：

- [ ] 会社概要の確認：代表者名、従業員数、拠点（資料では［確認中］）
- [ ] 事業の実態：施工内容の比率（外装金物／屋根・外壁板金など）、自社加工の有無、主な得意先の数と構成
- [ ] 受講者：氏名・役割（社長／営業・見積／職人／事務）・人数、一人親方の関わり方
- [ ] 業務の流れ：図面受領 → 拾い出し・見積 → 提案 → 加工・取付 → 請求、のどこで時間がかかり、どこで問題が起きているか
- [ ] 社長が最も伸ばしたい指標（見積件数／受注率／単価／追加工事）と、品質・納期の課題
- [ ] Microsoft 365の契約：プラン（Business Basic／Standard／Premium など）と人数、職人の方にも職場アカウントがあるか
- [ ] 自社クラウドの使い方：SharePoint／OneDriveのフォルダ構成、Teamsの利用状況
- [ ] 管理の窓口：社内のIT担当、または管理を任せている販売店
- [ ] 使っている機器とソフト：スマホの機種（iPhone／Android）、PC（Windows）、図面の形式（PDF・CAD）、見積・請求の作り方（Excel・会計ソフト等）
- [ ] 社内の推進役の候補（コース後に定着させる担当、事務または営業から1名）
- [ ] 社外に出せない情報の範囲（施主名、金額、図面、元請名など）
- [ ] 通話・打合せの録音について、現在の運用と社内の考え方
- [ ] 日程の希望：曜日・時間帯、繁忙期、職人が参加しやすい時間（夕方・雨天日）

### 2.2 事前アンケート（受講者全員）

- 担当業務と、1週間で時間がかかっている作業の上位3つ
- スマホ・PCの操作の得意・不得意（5段階）
- AIを使ったことがあるか、使ったことがあれば用途
- コースで解決したいこと（自由記述）

結果を見て、第1回の説明の深さと、実習の組分け（得意な人と不得意な人を組む）を決める。

### 2.3 KPIの基準値（受講前3か月）

先方に依頼して、月ごとの数字を集める。

| 区分 | 指標 | 依頼するデータ |
|---|---|---|
| 売上（主） | 売上 | 月別売上 |
| 売上 | 見積件数 | 見積書の発行件数（見積台帳、送付履歴） |
| 売上 | 受注率 | 受注件数（受注台帳） |
| 売上 | 平均受注単価 | 受注金額の合計 |
| 売上 | 追加工事の請求額 | 追加・変更工事の請求額 |
| 品質 | 手戻り・再施工 | 件数（記録がなければ聞き取りで概数） |
| 品質 | 元請からの指摘 | 件数（同上） |
| 納期 | 見積回答日数 | 図面受領日と見積提出日（直近10件程度） |
| 納期 | 図面受領から材料発注まで | 図面受領日と発注日（直近10件程度） |

- 記録がない指標は、受講開始から記録を始める（記録用の簡易シートを用意する）。
- 基準値が揃ったら、資料の目安（仮）を見直す。資料の目安は「売上＋10%程度」（見積件数＋5%、受注率＋1ポイント、単価＋2%、追加工事 月＋10万円）、品質（手戻り−30%、指摘−20%）、納期（見積回答日数−30%、受領から発注まで−20%）。
- 指標は掛け算で売上に効くため、個別の目標を上げすぎない。

### 2.4 教材データの受領と匿名化

依頼するデータ（各回で使う）：

| データ | 件数の目安 | 使う回 |
|---|---|---|
| 施工前の現場写真（手すり・笠木・庇・雨どい・屋根・外壁など） | 10件以上 | 第1・3回 |
| 施工中・施工後の写真 | 5件×2現場 | 第2・5回 |
| 過去の図面（PDF）と、それに対応する見積書 | 3〜5件 | 第4回 |
| 元請とのメール・連絡文の例 | 5件程度 | 第2回 |
| 請求書・追加工事の記録 | 数件 | 第5回 |
| 見積・受注・売上の台帳（CSV・Excel） | 直近6か月以上 | 第6回 |

匿名化の手順：

- [ ] 施主名・元請名・現場住所・担当者名・電話番号を伏せる（置き換え表を作り、講師だけが持つ）
- [ ] 写真の人物の顔、車のナンバー、表札を隠す
- [ ] 金額は、必要に応じて一定の係数を掛けて実額を伏せる（第4回の精度検証と第6回では実額の比率を保つ）
- [ ] 匿名化済みのデータだけを、受講者用の共有フォルダに置く
- [ ] データの受け渡し方法・保管期間・コース終了後の削除を、先方と書面で取り決める（必要なら秘密保持契約を結ぶ）

### 2.5 ツールとアカウント（Microsoft 365 Copilot 前提）

先方はWindows環境でMicrosoft 365（SharePoint／OneDrive）を使っている前提で、AIはCopilotに統一する。

| 用途（主な回） | 使う機能 | 対象 | 費用 |
|---|---|---|---|
| 文章・写真の説明・質問（第1・2回） | Microsoft 365 Copilot Chat（スマホのMicrosoft 365 Copilotアプリ、PCのブラウザ・Teams） | 全員 | 追加費用なし（職場アカウントが必要） |
| メール・Word・Excel・Teamsでの活用、社内ファイルの参照（第2・4・6回） | Microsoft 365 Copilot Business | 社長・営業／見積・事務（数名） | 有料の追加ライセンス（参考：1人あたり月3,000円前後） |
| 完成イメージ（第3回） | Copilotの画像生成・編集 | 社長・営業／見積 | 上記に含む |
| 打合せの録音・要約（第2・5回） | Teams会議の文字起こし＋Copilotで要約 | 社長・営業／見積・事務 | Teamsの文字起こしはMicrosoft 365の契約に含まれる。要約はCopilotのライセンスが必要 |
| 電話・現場の録音（第2・5回） | スマホで録音 → Wordの文字起こし → Copilotで要約 | 全員 | Wordの文字起こしは月あたりの時間に上限あり（Copilotのライセンスで拡大） |
| 保存・共有 | 現場ごとのSharePoint／OneDriveのフォルダ、Teamsの研修用チャネル | 全員 | 既存の契約内 |

準備のチェックリスト：

- [ ] 全員分の職場アカウント（職人の方の分がなければ追加を相談）
- [ ] Copilot Businessを付ける人（数名）と、販売店の見積の取得。**価格は公開情報の参考値。正式な金額は販売店の見積で確認する**
- [ ] 管理者の設定（IT担当・販売店に依頼）：Copilot Chatの利用、Teams会議の文字起こし、録音の保存先
- [ ] スマホへのMicrosoft 365 Copilotアプリの導入手順書（iPhone／Android、1枚）
- [ ] Teamsの研修用チャネル（教材の配布、宿題の提出、質問の受付）
- [ ] SharePointに研修用フォルダと、現場ごとのフォルダのひな形
- [ ] 会場：プロジェクターまたは大型モニター、Wi-Fi、電源タップ、テザリング用の予備回線

事前に必ず確かめること（結果は開講前に社長へ報告する）：

- [ ] **画像編集の品質（第3回）**：Copilotで手すり・笠木などを置き換えた画像が、提案に使える水準か。足りない場合は、画像編集に強い別サービス（例：Adobe Photoshopの生成塗りつぶし）を第3回だけ併用する案を出す
- [ ] **画像の商用利用**：職場アカウントでの利用を前提に、最新の利用規約を確認する
- [ ] **図面の読み取り精度（第4回）**：CopilotにPDF図面を読ませた結果を、過去の見積と比べる
- [ ] **文字起こしの精度と上限（第2・5回）**：現場の騒音がある録音でも使えるか、月の上限で足りるか
- [ ] **データの扱い**：職場アカウントのCopilotは商用データ保護の対象であることを、Microsoftの最新の説明で確認し、受講者向けにかみ砕いて伝える

個人のスマホに入っている無料のAIアプリ（職場アカウント以外）は、研修でも業務でも使わない。これをAI利用ルールに入れる。

### 2.6 AI利用ルール案（第1回で議論する叩き台）

1枚にまとめる。項目：

- 使うAIは職場アカウントのCopilotだけ。個人の無料AIアプリには業務の情報を入れない
- AIに入れてよい情報／入れてはいけない情報（施主の個人情報、未公開の図面、金額など）
- 録音の扱い：相手に録音を伝えるか、保存場所（SharePointの現場フォルダ）、保存期間、AIに渡してよい範囲
- AIの出力の扱い：見積・請求・提案など社外に出すものは、必ず人が確認する
- 画像生成の扱い：完成イメージは「参考」と明記し、施工前の写真と並べて出す
- 困ったときの相談先

録音や個人情報の扱いは、必要に応じて先方から専門家に確認してもらうよう伝える。講師が法的な判断を断定しない。

## 3. 各回の準備

### 共通の準備（毎回）

- [ ] 講義資料（20分、10枚程度）
- [ ] 実演の手順メモ（20分）。実演は本番と同じアカウント・同じデータで事前に1回通す
- [ ] 実習シート（60分）：課題、手順、完成の基準、つまずきやすい点
- [ ] 指示テンプレート（回ごとに追加し、テンプレート集にまとめる）
- [ ] 振り返りシート（20分）：できたこと、業務でどう使うか、宿題
- [ ] 予備の手段：AIが応答しない・遅いときに備え、出力例の画面と、オフラインで進められる課題を用意する

### 第1回　AIの基本と安全な使い方（対象：全員）

| 項目 | 準備内容 |
|---|---|
| 講義 | AIにできること・苦手なこと（もっともらしい誤りを出すこと）、Copilotアプリでの写真・音声・文章の渡し方、情報の扱い |
| 使う機能 | Microsoft 365 Copilotアプリ（スマホ）、Copilot Chat（PC） |
| 実演 | 現場写真をスマホで撮り、Copilotに劣化の状態と作業手順を書かせる |
| 実習の素材 | 匿名化した施工前の写真（受講者数×2枚） |
| 配布物 | AI利用ルール案（2.6）、スマホでの使い方の手順書（1枚） |
| 当日の注意 | 全員がCopilotアプリに職場アカウントでログインできるかを冒頭10分で確認する（講義資料2枚目「第1回までの準備」を使う）。スマホが苦手な人の隣に得意な人を座らせる |
| 宿題 | 1週間、毎日1回業務でCopilotを使い、使った内容をTeamsの研修用チャネルに投稿する |

### 第2回　文章業務と会話の記録を速くする（対象：全員、営業・事務は必須）

| 項目 | 準備内容 |
|---|---|
| 講義 | 指示の出し方（目的・相手・条件）、連絡文・報告書・お詫び文の型、通話・打合せの録音から要約と決定事項を作る方法 |
| 使う機能 | Copilot（Outlook・Word）、Teams会議の文字起こし、Wordの文字起こし |
| 実演 | 工程変更の連絡文、施工写真5枚から施工報告書、録音から要約と確認の連絡文 |
| 実習の素材 | 実際の工程変更の事例（匿名化）、施工写真5枚×2現場、**模擬の通話録音（講師が台本を書き、2人で録音して用意する）** |
| テンプレート | 連絡・報告・お詫び・通話の要約 |
| 当日の注意 | 実在の通話録音は使わない（模擬のみ）。録音の扱いのルールを第1回の案と照らし合わせて確認する |
| 測る | 連絡文・報告書1件の作成時間（受講前の自己申告と比較） |

### 録音テーマ（第2回・第5回で扱う）

- 模擬の通話台本：元請からの工程変更、現場での追加の口頭指示、各2〜3分
- 抽出させる項目：決定事項、宿題（誰が・いつまでに）、追加工事の候補と根拠
- 運用のルール：相手への伝え方の例文、保存場所と期間、AIに渡す範囲

### 第3回　現場写真から完成イメージを作る（対象：社長・営業／見積）

| 項目 | 準備内容 |
|---|---|
| 講義 | Copilotの画像編集への指示（置き換える対象・変えない部分・画角）、色・素材違いの案の作り方、提案書での見せ方と注意点 |
| 使う機能 | Copilotの画像生成・編集、PowerPoint（提案書のひな形）。品質が足りない場合は2.5の併用案 |
| 実演 | 1枚の写真から、手すり・笠木・庇などの完成イメージを標準仕様と上位仕様の2〜3案で作る |
| 実習の素材 | 受講者ごとに自社の施工前写真3件。施工内容がばらけるように選ぶ |
| 事前検証 | **講師が事前に全素材で生成を試し、うまく出ない写真（画角・明るさ・写り込み）を差し替えておく** |
| テンプレート | 施工内容別の指示テンプレート（手すり交換、庇の新設、雨どい交換、屋根・外壁の板金カバー、目隠しルーバー、笠木の更新） |
| 配布物 | 完成イメージ付き提案書のひな形（施工前写真・完成イメージ案・注記「完成イメージ（参考）」） |
| 当日の注意 | 図面どおりに出ないことがある点を必ず伝える。寸法・納まり・色は実物見本と施工図で確認する運用にする |
| 測る | 完成イメージ付き提案の件数（以後、月次で記録） |

### 第4回　図面と見積にAIを使う（対象：社長・営業／見積）

| 項目 | 準備内容 |
|---|---|
| 講義 | 図面PDFから部材と数量（m・か所）を拾わせる指示、発注リスト・加工寸法表の下書き、見積の前提条件・除外項目の文案 |
| 使う機能 | Copilot（PDFの読み込み）、ExcelのCopilot（発注リスト・加工寸法表） |
| 実演 | 過去の図面1件で拾い出し → 発注リストの下書き |
| 実習の素材 | 過去の図面3〜5件と、それに対応する実際の見積書（正解データ） |
| 事前検証 | **講師が事前に全図面でAIの拾い出しを試し、実際の見積との差（部材の漏れ、数量の差）を一覧にしておく** |
| 配布物 | 精度検証シート（部材ごとに、AIの数量・実際の数量・差・原因） |
| テンプレート | 拾い出し、発注リスト、加工寸法表、見積の前提条件 |
| 当日の注意 | AIの数量をそのまま使わない。どの部材なら任せられ、どこは人が見るべきかを、検証結果をもとに受講者と一緒に決める |
| 測る | 見積回答日数、図面受領から材料発注までの日数（以後、月次で記録） |

### 第5回　現場の記録と請求漏れ防止（対象：職人・事務）

| 項目 | 準備内容 |
|---|---|
| 講義 | 写真・音声メモ・打合せの録音で日報と追加工事を記録する方法、ベテランの施工のコツを手順書にする方法、月末の請求候補一覧の作り方 |
| 使う機能 | Copilotアプリ（写真・音声）、Wordの文字起こし、SharePointの現場フォルダ |
| 実演 | 模擬の現場で追加指示を受けた想定 → 写真と録音で記録 → 請求候補一覧と根拠写真 |
| 実習の素材 | 模擬の現場（会議室の一角や自社の加工場で再現）、模擬の追加指示の台本、ベテラン職人へのインタビュー（事前に10分録音させてもらう） |
| 配布物 | 現場記録の手順書（1枚、職人向けに大きな文字で）、請求候補一覧のひな形、施工手順書のひな形 |
| 当日の注意 | 職人の入力は「撮る・話す」だけにする。整理は事務とAIが行う流れを、役割分担として明確にする |
| 測る | 追加工事の請求額、手戻り・再施工の件数（以後、月次で記録） |

### 第6回　売上で振り返り、社内に定着させる（対象：全員）

| 項目 | 準備内容 |
|---|---|
| 講義 | 売上と4つの要素、品質・納期の指標の読み方 |
| 使う機能 | ExcelのCopilot |
| 実演 | 見積・受注データ（CSV）から、指標の月次推移をExcelのCopilotで集計する |
| 実習の素材 | 受講前3か月と受講中の月次データ（講師が事前に集計し、AIでの集計結果と照合しておく） |
| 発表 | 各自5分。業務で使った事例と、売上・品質・納期への効き方 |
| 配布物 | AI利用ルール（確定版）、テンプレート集一式、売上・品質・納期の月次集計表 |
| 当日の注意 | 数字の変化を受講者の評価に使わない。うまくいったやり方を社内の標準にすることに焦点を当てる |

## 4. 期間中の運用

- **回の間の質問対応**：Teamsの研修用チャネルで受け付け、原則として翌営業日までに回答する。よくある質問は次回の冒頭で共有する。
- **社内の推進役との定例**：各回の後に15分、推進役（事務または営業の1名）と、使われ方・困りごと・KPIの記録状況を確認する。コース後は推進役が運用を引き継ぐ。
- **見直しのタイミング**：第3回の後と終了時に、社長と30分で数字を確認する。効果が見えない施策は、残りの回の内容を組み替える。
- **宿題の確認**：提出内容から、業務で使われ始めた用途を拾い、次回の実習の題材に取り込む。
- **月次のKPI報告**（社長向け、A4で1枚）：
  - 売上と4つの要素（見積件数・受注率・平均受注単価・追加工事の請求額）
  - 品質（手戻り・指摘）、納期（見積回答日数・受領から発注まで）
  - 基準値との比較、効いた取り組み、次月の重点
- **記録**：各回の出席、実習の到達度、出た課題、次回への申し送り。

## 5. リスクと対策

| リスク | 対策 |
|---|---|
| AIのサービスが当日つながらない・遅い | 出力例の画面とオフラインの課題を用意する。テザリング用の回線を持参する |
| Copilotの設定が開講に間に合わない | 開講3週前に設定を依頼し、1週前に講師のテスト用アカウントで動作を確認する。間に合わない機能は、その回の実演を講師の画面で行う |
| 個人の無料AIアプリに業務情報を入れてしまう | 第1回でルール化し、職場アカウントのCopilotだけを使うことを繰り返し伝える |
| 完成イメージが図面どおりに出ない | 事前に全素材で試して差し替える。「参考イメージ」と明記する運用をルールに入れる |
| 拾い出しの精度が低い | 精度検証の結果をもとに、AIに任せる範囲を絞る。チェック役から始める |
| 職人が参加しにくい | 必須を3回（計6時間）に絞り、夕方・雨天日で日程を調整する。手順書は1枚・大きな文字で |
| 情報の取り扱いへの不安 | 匿名化の手順と、データの保管・削除の取り決めを開講前に書面で合意する |
| KPIの記録が続かない | 記録用の簡易シートを用意し、月次報告の前に事務担当と一緒に集計する |
| 数字が伸びない | 4つの要素のどこが動いていないかを見て、該当する回の内容を補講やフォローで補う |
