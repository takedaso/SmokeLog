# ユースケース：小規模な建設機材卸売会社

> デモ（docs/demo/receipt-ledger.html）の想定業務。業界事例と建設業向け経費精算の一般的な論点をもとに整理した。会計・税務の扱いは一般論であり、運用時は顧問税理士に確認すること。

## 1. 想定する会社

| 項目 | 内容 |
|---|---|
| 事業 | 足場・発電機・小型建機・仮設資材の販売とレンタル、現場への配送、機材の整備 |
| 従業員 | 約10名（営業3〜4名、配送・倉庫3名、整備1〜2名、事務1〜2名） |
| 得意先 | ゼネコン、工務店、土木会社、リフォーム会社 |
| 車両 | 2tユニック・4t平ボディ（配送）、営業車、整備用の軽バン |
| 領収書 | 1人あたり月100枚前後（設計上の上限は月1,000枚/人） |

## 2. 発生する領収書と扱い

| 誰が | 典型的な領収書 | 勘定科目の例 | 紐付け先 |
|---|---|---|---|
| 配送 | 軽油・ガソリン、高速代（現金）、現場周辺の駐車場 | 車両費、旅費交通費 | 現場（工事番号）＋車両 |
| 配送・営業 | 急ぎの配送便（緊急の部材手配） | 荷造運賃 | 現場 |
| 営業 | 現場所長との打合せ飲食、受注御礼の会食 | 会議費、交際費 | 得意先・現場 |
| 現場対応 | ホームセンターでの養生テープ・ボルト等の買い足し | 消耗品費 | 現場 |
| 整備 | 機材・車両の部品、外注修理 | 修繕費 | 車両（現場に紐付かない＝販管費） |

## 3. 業界事例から取り入れた論点

| 論点 | 事例・解説での指摘 | デモでの対応 |
|---|---|---|
| 工事番号の付与 | 申請時に工事番号を選ばせ、該当しない支出は入力を省く分岐を用意する。全件必須にするとダミー番号で集計が汚れる | 「現場・案件（工事番号）」を任意項目にし、未選択は販管費として自動区分 |
| 現場経費と本社経費の区分 | 現場の燃料・高速・備品は工事原価、本社の経費は販管費と分けて扱う | 区分（現場原価／販管費）をホームと集計に表示 |
| 現場での立替の振り分け | 立て替えた駐車場代や資材の買い足しを、後から誰かが現場ごとに振り分けている | 前回の現場を初期値にし、撮影したその場で現場を選べる |
| モバイルでの即時登録 | 現場でレシートを撮影し、工事番号を選んで申請する。紙の紛失防止にもなる | スマホ撮影→AI読取→確認の3ステップ |
| 紙の削減 | 建設会社で月3,000枚の領収書をペーパーレス化した事例がある | 画像を正本として保存し、変更履歴を残す |

## 4. 気の利いた機能（デモで実装）

1. **取引先の業種から科目を推定**：ガソリンスタンド→車両費、高速・駐車場→旅費交通費、配送→荷造運賃、部品・整備→修繕費。同じ取引先の過去の確定分があれば、その科目と車両を引き継ぐ。
2. **車両別の燃料管理**：給油量（L）をAIで読み取り、1Lあたりの単価を表示。車両別に燃料費・給油量を集計できる。
3. **飲食費の1人1万円判定**：参加人数を入力すると1人あたりの額を計算し、交際費から除外できる飲食費（1人1万円以下）に当たるか、交際費になるかを表示する。相手先のメモを促す。
4. **インボイス登録番号の確認**：登録番号のない領収書に、仕入税額控除の経過措置（2026年10月以降は50%）の対象となる旨を表示する。
5. **電子帳簿保存法の入力期限**：取引日から60日を超えた未確定の領収書に、入力期間の目安（おおむね2か月と7営業日以内）を表示する。
6. **10万円以上の工具・備品**：固定資産の対象になり得る旨を表示する。
7. **経理チェック**：ホームに「登録番号なし」「飲食で人数未記録」「車両費で車両未選択」の件数を出し、タップで該当の領収書を一覧表示する。
8. **取引先マスタの自動登録**：AIが読み取った取引先を支払先マスタと照合し、未登録なら確定時に登録する。得意先（ゼネコン等）とは分けて管理する。

## 5. デモの流れ（10分）

1. ホームの「サンプルデータを入れる」で、得意先4社・現場5件・車両4台・領収書13枚（9〜11月）を投入する。
2. ホームで、今月の現場原価と販管費の内訳、現場別・得意先別・月別の集計を見せる。
3. 要確認の「ミナトモータース（2tユニック 油圧ホース交換）」を開き、車両と区分の表示、確定の流れを見せる。
4. 経理チェックの「車両費で車両未選択」をタップし、営業車の給油に車両を設定する。
5. 手元のレシートを撮影し、AI読取→科目の推定→チェック表示→確定までを実演する。
6. 集計で「車両別」「現場別」を切り替え、CSVで保存する。
7. 終了後、マスタの「サンプルデータを削除」で元に戻す。
